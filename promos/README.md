# Plugin Store promo images

Marketing images for the CSR listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-csr](https://justinholt.com/plugins/craft-csr).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `csr-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp). **Promos are JPEG, never PNG** — Chrome can only write PNG, so
`build.sh` converts with `sips` at quality 90 and deletes the intermediate.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, editions | — |
| 2 | Write the page they looked for | **real** screenshot of the Searches report |
| 3 | Measured, not inferred | **real** screenshot of the Deflection report |
| 4 | The answer, before the ticket | the support form's suggestion panel, drawn with its real labels |
| 5 | A clock that pauses | a ticket's SLA timeline, with the pending time given back |
| 6 | Nobody needs an account | **real** screenshot of a ticket |
| 7 | Lite is a desk, not a demo | the two editions |

Slide 4 uses the form's own strings — "What is it about?", "In one line, what is happening?",
"These might already answer it", "Yes — that answers it". Change them in
`src/templates/_support/form.twig` and change the slide. Slide 5's arithmetic has to add up:
31 business hours, less 19 pending, is 12 against a 16-hour target.

Pricing appears on slides 1 and 7. It is also in the marketing page seed, the README, the docs and
the Craft Console listing — see the `plugin-marketing-site` skill in `~/Sites/justinholt`.

## Palette

Accent `#B0774D`, the midpoint of the icon tile's gradient (`#D89B6D` → `#89532E`), with
`#E3B08A` as the light accent for anything small on the dark background and the family's `#ffd166`
gold. Jersey 20 for display, Inter for body.

## The watermark is the headset alone

`assets/watermark.svg` is the headset from `../src/icon.svg` in white with the tile stripped: at
watermark scale the rounded square reads as a grey box across the slide. It is switched off on the
cover, where it sat behind the icon like a shadow. `assets/icon.svg` is a straight copy of
`../src/icon.svg`; re-copy it whenever the icon changes.

## Screenshots

`shots/` holds four captures, also used on the marketing page
(`~/Sites/justinholt/web/images/plugins/screenshots/craft-csr/`). They are element screenshots of
`#main-container` from the plugin-testing harness at 1280 CSS px and 2×, with the harness's own
chrome (global sidebar, header, queue bar, footer, debug panels) hidden, over a demo data set of
articles, tickets, searches, ratings and deflection sessions that was removed afterwards.

`fonts.css` is generated by `build.sh`; don't edit it.
